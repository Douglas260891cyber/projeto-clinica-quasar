# Projeto Clínica Quasar

Este projeto foi reorganizado em dois módulos principais:

- frontend/: aplicação Quasar/Vue
- backend/: API Node.js/Express com PostgreSQL

## Como executar

### Frontend

```bash
npm --prefix frontend install
npm run dev:frontend
```

### Backend

```bash
npm install
npm run dev:backend
```

## Estrutura

```text
backend/
frontend/
```
